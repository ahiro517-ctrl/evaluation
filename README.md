# evaluation

花咲爺さんズ 評価・報酬制度（2026年7月運用開始）を、Googleスプレッドシート上で
運用するための評価シートと、それを生成・運用するGAS（Google Apps Script）。

## ステータス

- ✅ 設計: [`docs/評価シート設計書.md`](docs/評価シート設計書.md)
- ✅ GAS実装: [`src/`](src)（clasp push 対象）
- ✅ セットアップ手順: [`docs/セットアップマニュアル.md`](docs/セットアップマニュアル.md)

## 制度の概要

半期（前期 7〜12月／後期 1〜6月）ごとに、粗利・バリュー・スキルの3要素で評価し、
昇降給・昇格・降格につなげる。詳細は設計書を参照。

## 使い方（概要）

スプレッドシートにバインドしたApps Scriptへ `clasp push` し、
メニュー「評価運用 → 評価シートを生成」で全シートを自動生成する。
手順の詳細は [セットアップマニュアル](docs/セットアップマニュアル.md) を参照。

```bash
cp .clasp.json.example .clasp.json   # scriptId を貼る
clasp push
```

## 構成

```
src/
  appsscript.json   マニフェスト
  constants.gs      制度マスタ定数（唯一の正）
  build.gs          スプレッドシート生成・数式/入力規則の注入
  logic.gs          昇格・降格の連続判定／確定→履歴追記
  interview.gs      個人面談シート（縦型・1人1枚）の生成
  menu.gs           「評価運用」メニュー
docs/
  評価シート設計書.md
  セットアップマニュアル.md
```
