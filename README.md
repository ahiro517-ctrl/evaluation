# evaluation

花咲爺さんズ 評価・報酬制度（2026年7月運用開始）を、Googleスプレッドシート上で
運用するための評価シートと、それを生成・運用するGAS（Google Apps Script）。

## ステータス

- ✅ 設計フェーズ: [`docs/評価シート設計書.md`](docs/評価シート設計書.md)
- ⬜ 実装フェーズ: GAS（`constants.gs` / `build.gs` ほか）

## 制度の概要

半期（前期 7〜12月／後期 1〜6月）ごとに、粗利・バリュー・スキルの3要素で評価し、
昇降給・昇格・降格につなげる。詳細は設計書を参照。

## ドキュメント

- [評価シート設計書](docs/評価シート設計書.md) — スプレッドシート構成、マスタ定義、
  計算ロジック、運用フロー、GASモジュール構成、確認したい論点。
